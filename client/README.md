# Apartment Investment Calculator Client

This is the frontend client for the Apartment Investment Calculator application. It provides a user interface for calculating real estate investment metrics and managing saved calculations.

## Setup

1. Install dependencies:
```
npm install
```

2. Start the development server:
```
npm start
```

3. Build for production:
```
npm run build
```

## Features

- Calculate real estate investment ROI, cash flow, and other financial metrics
- Mortgage payment calculations based on actual mortgage tables
- Save and load investment scenarios
- Visualize investment performance over time

## Technology Stack

- React.js
- Webpack
- Emotion (CSS-in-JS)
- Chart.js for visualizations
- Axios for API communication
